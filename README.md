# نظام إدارة الموظفين

موقع متكامل فيه:
- تسجيل دخول بيوزرنيم وباسورد (موظف / أدمن)
- تسجيل حضور وانصراف بالصورة واللوكيشن (بيتبعت على تيليجرام زي الأول)
- لوحة أدمن: إضافة/إدارة الموظفين، متابعة الحضور يوم بيوم، خصومات (يدوي + أوتوماتيك من الغياب/التأخير)، توزيع ليدز على الموظفين، رسائل مباشرة مع كل موظف
- لوحة موظف: تسجيل الحضور، شوف خصوماته، شوف الليدز المتوزعة عليه ويحدّث حالتها، يبعت رسايل للإدارة

كل البيانات بتتخزن في ملف `data/db.json` (بيتعمل أوتوماتيك أول مرة تشغّل السيرفر) - مفيش قاعدة بيانات منفصلة محتاجة تتركب.

## 1. التركيب

محتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
cp .env.example .env
```

افتح `.env` واملى:
- `BOT_TOKEN` و `CHAT_ID` (لو عايز إرسال تيليجرام لتسجيل الحضور - اختياري، الموقع يشتغل من غيرهم برضو)
- `SESSION_SECRET` - أي نص عشوائي طويل (مهم للأمان)

```bash
npm start
```

## 2. أول دخول

أول ما تشغّل السيرفر لأول مرة، هيتعمل حساب أدمن افتراضي وهيظهر لك في الـ Terminal:
```
Username: admin
Password: admin123
```

روح `http://localhost:8080` وادخل بيهم، وغيّر كلمة السر فورًا من تبويب "الإعدادات" في لوحة الأدمن.

## 3. إضافة الموظفين

من لوحة الأدمن → تبويب "الموظفين" → اكتب الاسم واسم مستخدم وكلمة سر لكل موظف، وابعتهملهم عشان يدخلوا بيهم على نفس اللينك.

## 4. الحضور والخصومات

- كل موظف بيسجل حضور/انصراف بالصورة من لوحته
- تبويب "الحضور والانصراف" في لوحة الأدمن بيوريك مين حضر/غاب/اتأخر في أي يوم
- زرار "توليد خصومات الغياب/التأخير لليوم ده" بيحسب أوتوماتيك خصم لكل موظف غاب أو اتأخر عن المعاد المحدد في الإعدادات (مش هيكرر نفس اليوم مرتين)
- تقدر كمان تسجل خصم يدوي لأي سبب من نفس التبويب

## 5. توزيع الليدز

من تبويب "توزيع الليدز": ضيف عميل محتمل، وزّعه على موظف من القائمة المنسدلة. الموظف هيشوفه في لوحته ويقدر يحدّث حالته (متوزع / تم التواصل / مقفول).

## 6. الرسائل

كل موظف عنده شات مباشر مع الأدمن من لوحته. الأدمن من تبويب "الرسائل" يقدر يختار أي موظف من القايمة ويبعتله.

## 7. تشغيله لكل الموظفين (مش بس على جهازك)

الموقع لازم يكون على سيرفر بـ HTTPS عشان المتصفح يسمح بالكاميرا والموقع على الموبايل. ارفعه على نفس سيرفر الجونة بتاعك خلف Nginx مع SSL، أو أي استضافة Node بسيطة (Railway, Render, VPS خاص بيك).

## ملاحظات مهمة

- `SESSION_SECRET` سري زي التوكن بالظبط - متشاركوش
- لو عايز تبدأ من الصفر، احذف فولدر `data` وهيتعمل حساب أدمن جديد تلقائي أول ما تشغّل السيرفر تاني
- الموقع بيطلب إذن صريح من المتصفح للكاميرا والموقع وقت تسجيل الحضور بس
